# Human-AI Collaboration

## 沟通原则

### 清晰表达
- 明确你的目标
- 提供上下文
- 说明约束条件

### 迭代优化
- 先看整体
- 再改细节
- 逐步完善

## 任务分解

### 复杂任务
```
目标 → 子任务1 → 子任务2 → 子任务3 → 整合
```

### 小步快跑
- 每个子任务可独立验证
- 快速反馈
- 及时调整

## 反馈技巧

### 有效反馈
- "这个方向对" / "这个不对"
- "加上XXX功能"
- "这部分需要优化"

### 避免模糊
❌ "再改改"
✅ "把错误处理加上"

## 工具选择

| 任务类型 | 推荐工具 |
|----------|----------|
| 代码生成 | AI Assistant |
| 代码审查 | AI + 人工 |
| 调试 | 断点 + AI |
| 重构 | AI + 测试 |

## 最佳实践

1. **先理解，后生成** - 确保AI理解你的需求
2. **验证输出** - AI可能出错
3. **保持控制** - 你决定做什么
4. **记录决策** - 为什么这样做
