# Project Planning Skill

## 目标
将模糊的需求转化为可执行的项目计划

## 流程

### 1. 需求理解
- 明确目标（做什么）
- 识别约束（时间/资源/技术）
- 定义验收标准（怎么做才算成功）

### 2. 任务分解
```
目标
├── 模块A
│   ├── 子任务A1
│   └── 子任务A2
├── 模块B
│   ├── 子任务B1
│   └── 子任务B2
└── 集成测试
```

### 3. 优先级排序
- MVP 功能优先
- 依赖关系排序
- 风险高的先做

### 4. 时间估算
- 按小时/天估算
- 留 20% buffer
- 里程碑设定

## 输出格式

```markdown
# 项目计划

## 目标
[一句话描述]

## 里程碑
| 阶段 | 内容 | 预计时间 |
|------|------|----------|
| M1 | 完成XX | 第X天 |
| M2 | 完成YY | 第X天 |

## 任务列表
- [ ] 任务1
- [ ] 任务2

## 风险识别
| 风险 | 影响 | 应对 |
|------|------|------|
| 风险1 | 高 | 方案X |
```

## 适用场景
- 新项目启动
- 大功能开发
- 团队协调
